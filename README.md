## API 

- `GET /`  Check API server status
- `GET /movies`  Retrieve all movies
- `GET /directors`  Retrieve all directors
- `GET /actors` Retrieve all actors
- `GET /characters`  Retrieve all movie characters
- `POST /movies` Insert a new movie
